# Alerte_Discord

Recueil de scripts qui envoient des alertes/notifications sur Discord via webhook, chacun dans son propre dossier.

## Dossiers

| Dossier | Description |
|---|---|
| [`daily_motivation/`](./daily_motivation) | Envoie un message d'encouragement automatique sur Discord, un jour sur deux, du 04/08/2026 au 07/11/2027 (via GitHub Actions). |
| [`emploi/`](./emploi) | Surveille des pages d'offres d'emploi (OpenClassrooms Mentors, Amazon Jobs Toulouse) et alerte sur Discord dès qu'un changement est détecté. |

Chaque dossier contient son propre `README.md` avec les instructions d'installation et de configuration détaillées.
